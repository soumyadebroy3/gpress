    gpress tries the levels in order, 0 first, and keeps the first result that fits; if none fits, you get the smallest. Levels 60 and above reduce image quality.

    A file gpress cannot safely make smaller comes back unchanged, with the reason. gpress is open source under the MIT or Apache-2.0 licence.
